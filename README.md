# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

The HR Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI.

The dashboard helps analyze employee data and provides insights into employee attrition, departments, salary slabs, age groups, gender, job roles, and total employee distribution.

## 🎯 Project Objectives

- Analyze employee attrition patterns
- Understand department-wise employee distribution
- Analyze attrition across different salary slabs
- Study age group and gender-wise employee data
- Analyze job role-wise attrition
- Understand the relationship between experience and attrition
- Create an interactive dashboard for HR analysis
- Support data-driven HR decision making

## 📈 Key KPIs

- **Total Employees:** 1,419
- **Active Employees:** 1,186
- **Attrition Count:** 233
- **Attrition Rate:** 16.4%
- **Average Age:** 36.93 years
- **Average Experience:** 7.04 years

## 🔍 Dashboard Features

- 👥 Employee Overview & KPI Cards
- 📊 Attrition by Department
- 💰 Attrition by Salary Slab
- 👨‍💼 Job Role-wise Attrition Analysis
- 🎂 Age Group Distribution
- ⚥ Gender-wise Attrition Analysis
- 📉 Attrition Trend by Experience
- 🏢 Department-wise Employee Count
- 🔎 Interactive Age Group Filters
- 🔎 Department-wise Filtering
